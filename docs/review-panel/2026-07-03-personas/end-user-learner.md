# Persona: End-User / Target Learner — 2026-07-03

**1. No exercise exists to evaluate yet — I can't tell if I'm "in."** Both docs are explicit that "exact exercise specs and rubrics per module" are out of scope for this pass (workshop-design.md line 73). The entire pitch is "you learn by doing it inside a harness, not by reading about it" (line 22), but there's nothing to *do* here — no sample module, no walkthrough of what a Coachgremlin session looks like. As the advertised learner, my honest reaction to these docs alone is "come back later" — I can't judge whether I'd bounce because there's no exercise to bounce off of. That's fine for an internal design doc, but if this is what a prospective learner sees, it under-delivers on its own premise.

**2. The audience bar is stated but untested against real friction points.** Line 11-14 says it assumes "comfort with git, CLI tools, and reading diffs" and "regular use of at least one coding agent already" — that's accurately calibrated to me, not condescending. But it doesn't say what harness version/features are assumed. Harness engineering module 3 name-drops "sub-agents/specialists, reusable skills, plugins/connectors (MCP and friends), isolated worktrees" (line 34) — if I'm a daily Cursor user rather than Claude Code, several of those concepts (skills, worktrees-as-a-harness-feature) may not map onto my tool at all. The doc says "your own harness" (line 18) but the module content leans on vocabulary from one specific harness's feature set. Worth flagging now, before content is written, whether exercises will be harness-agnostic or Claude-Code-specific with a "translate to your tool" burden on the learner.

**3. The capstone is the one exercise concept described, and it's promising.** "Diagnose which of the four is the bottleneck in a deliberately broken agent task, then fix it" (line 36) is the one moment in these docs where I can picture actually sitting down and doing something. That's the strongest signal I'd stay engaged. I'd want more of that concreteness pulled earlier — right now the four-module list (lines 32-36) is all definition, no task, until the capstone.

**4. Self-paced with no facilitator, but "sets the rubric up front" — will Coachgremlin actually catch it when I'm wrong?** Line 25 promises feedback "against the learner's actual attempt," not a lecture or handed-over solution. As a daily agent user, my real skepticism is whether a rubric-driven grader agent can tell the difference between "I solved it a different valid way" and "I missed the point" — this is the single biggest risk to whether I trust the workshop's verdicts on my work, and it's asserted, not shown, in either doc.

No complaints on tone or pitch calibration — the audience framing itself (not intro-to-AI, no assumed vocabulary for the two coined terms) is exactly right for someone in my seat.
