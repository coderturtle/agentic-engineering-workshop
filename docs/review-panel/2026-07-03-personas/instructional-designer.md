# Persona: Instructional Designer / Pedagogy Reviewer — 2026-07-03

**1. Module 1's objective may already be met by the target audience.** The design states the audience "have absorbed prompt engineering by osmosis" (workshop-design.md, line 7), yet Module 1 teaches exactly that skill, and it's the *only* module with no named exercise pattern to anchor it — implementation-plan.md flags it as "no external named pattern yet ... note 'atomic unit, necessary-but-insufficient framing'" (§1, line 32). "Necessary but insufficient" justifies the module's place in the narrative arc, but it doesn't establish what new capability an advanced practitioner gains. Risk: the entry module reads as review, not instruction, which is a bad way to open a workshop aimed at people who already do this daily.

**2. Module 2 (context engineering) has no exercise-pattern anchor at all.** The exercise-material list in implementation-plan.md §1 gives concrete pointers for 01, 03, 04, and 05 but skips 02 entirely — not even a placeholder note like Module 1's. Without some anchor, there's no way to tell whether "curate what the model can see" (workshop-design.md, line 33) becomes an exercise that forces actual curation tradeoffs, versus one that just talks about them.

**3. The module order is justified as a historical arc, not a verified skill dependency.** "The workshop's spine is the evolution of practice, in order" (line 30) argues chronology, not prerequisite necessity. Each module "gets at least one Coachgremlin-run exercise with its own rubric" (line 65) — nothing indicates exercises are cumulative (e.g., that the harness-engineering exercise requires reusing a context-engineering decision from Module 2). Independent, self-contained exercises undercut the claim that the sequence "really builds."

**4. Module 4 is asked to teach four distinct sub-concepts (agent/verification/event-driven/hill-climbing loops) plus three named patterns, but gets the same "at least one exercise" budget as every other module (line 65).** That's a lot of taxonomy for one assessment to cover honestly.

**5. The capstone's synthesis claim can't yet be verified.** Its spec is one sentence (line 36), and with exercise specs explicitly deferred (line 73), nothing currently guards against the capstone reusing the same "broken task" shape as Module 4's own exercises rather than genuinely requiring cross-layer diagnosis.
