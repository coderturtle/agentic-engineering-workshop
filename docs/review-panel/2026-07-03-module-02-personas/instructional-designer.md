# Persona: Instructional Designer — Module 02 — 2026-07-03

**The cumulative hook is asserted, not mechanically wired.** Line 21 claims "You already hold a proven prompt from Module 01; this exercise lands hard precisely because of that." But the exercise instruction (line 27) never tells the learner to *reuse* that specific prompt — it just says "a single prompt that implements `group_expenses_by_month` correctly, first try." Module 01's takeaway explicitly tells the learner to save their winning prompt as "a personal snippet library, a slash command... (`.claude/commands/spec-impl.md`)" — but Module 02's exercise text never points back at that artifact, never says "pull out your saved command from Module 01," and never checks that the prompt used here *is* the Module 01 one. A learner who writes a fresh prompt from scratch (or who skipped Module 01 entirely) satisfies the letter of the exercise identically. The "hook" is real prose continuity but not an enforced mechanical one — nothing in the rubric or gate verifies prompt provenance. This is the single biggest gap between the module's stated pedagogical claim and what the exercise actually checks.

**The hands-on gate itself is real and unambiguous.** "Required to advance" (line 42) names concrete artifacts — curated context, task output, written justification — checked against the rubric, and explicitly disclaims passive reading ("Reading this module does not count"). This is a solid, checkable gate, on par with Module 01's.

**Rubric redundancy.** Criterion 4 ("nothing load-bearing was cut") substantially overlaps criterion 3 ("necessary inclusion... present verbatim"): if 3 is satisfied, 4's substantive claim is already true by construction — a grader checking 3 has effectively already checked half of 4. The only non-redundant part of 4 is the documentation act (did the write-up *name* the cuts), which is really a writing-quality check, not an independent content check. Similarly, gate 2 ("task still correct") partially subsumes 3 — if tests pass, the load-bearing lines were necessarily present in *some* form; criterion 3 only adds value by requiring verbatim (not paraphrased) inclusion, which the rubric doesn't make explicit as the distinguishing factor. Tightening 3 and 4 into one criterion with two named sub-checks (presence verbatim; write-up accuracy) would remove the overlap without losing coverage.
