# Persona: Instructional Designer — Module 04 — 2026-07-03

**Finding 1 (top): the core teaches roughly 1.5 of the module's 4 stated learning objectives, not "the two load-bearing layers" the plan claims.** LO1 (stop condition) and LO4 (stable-goal-vs-moving-target) are genuinely gated in the required exercise, rubric criteria 1, 2, and 5. LO2 ("Add a verification pass that checks output against a rubric") is thinned to "the loop's done signal is the test suite's result" (rubric criterion 3), a binary pass/fail check, not a rubric-graded verification pass. The actual rubric-based verification the LO describes is Extension A ("Verification loop, deepened... blast radius"), which is optional and, per the README's own footer, "not yet authored." LO3 (hill-climbing safety) has **zero hands-on component in the required path**, it appears only as prose in "Loop taxonomy used here" ("a proposed rewrite is only adopted if it passes verification... and a human reviews it, never auto-applied"), which the learner reads but never practices. The exercise that would operationalize it is Extension C, also unauthored. The implementation plan's claim that "the core covers the two load-bearing layers (agent loop plus verification loop)" overstates what's actually gated, verification is present in name only.

**Finding 2: the hands-on-by-design gate is real but narrower than the module it gates.** "Required to advance" genuinely requires a fired terminal state, not reading (confirmed by the dry-run's discrimination test in `grading.md`/`retro.md`). But a learner can clear Module 04 having never reasoned hands-on about hill-climbing safety at all, the objective most tied to the workshop's own safety finding (panel items #2 and the AI/ML/Security reviewer catch) is the one objective entirely optional.

**Finding 3: rubric criteria 3 and 4 overlap on the same failure mode.** Criterion 3 ("the suite itself was not modified by the fix being verified") and criterion 4 ("`tests/test_grouping.py` is out of bounds entirely") both fire on the identical gaming move, editing the test file. One violation trips two scored/gate criteria, effectively double-weighting a single check rather than covering two distinct skills.
