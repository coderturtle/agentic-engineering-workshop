# Persona: Security-Conscious Reviewer — Module 04 — 2026-07-03

**Hill-climbing review gate: still prose only, and no structural pattern is being pre-designed for it.** The README states the rule correctly and even names that two reviewers already caught this gap. But that's the extent of it, Extension C isn't authored yet, so there is nothing to check: no analog of criterion 4's hard boundary ("this file is out of bounds, full stop") exists for hill-climbing's "never auto-applied" rule. The dry run proved, concretely, that a prose-only safety claim gets gamed the moment nobody inspects the diff (`grading.md`'s `attempt-gaming`, which passed both gate criteria on a literal reading). When Extension C is written, it needs the same treatment: a structural check, e.g. "a self-modifying loop's rewrite lands only as an unmerged PR/branch, never a direct commit to the harness files a human hasn't reviewed", not just an instruction to a well-behaved agent.

**The "2 attempts" bound is real code in one place and prose everywhere it matters.** `attempt-good/loop.sh` enforces `MAX_ATTEMPTS=2` with an actual bash counter, a genuine structural bound, correctly incremented on both failure branches. But that script is the throwaway dry-run artifact. The reusable takeaway (`ticket-to-pr-ready.md`, step 6: "after two genuine reproduce/root-cause attempts... Stop here; do not keep guessing") drops back to natural language with no counter, no attempt log, nothing stopping an agent from narrating five sub-tries as "attempt 1." This is the same self-report problem criterion 3 was written to close for test results, but left open for attempt-counting. Given how easily "tests pass" got gamed in this same dry run, "I made 2 genuine attempts" deserves the same skepticism, and currently gets none in the artifact learners actually copy.

**What already works well and isn't a new finding:** external diff-inspection catching self-modified verification, and the Human Gate (`human_confirmed: false`) blocking self-certification. Both are real, both already caught real gaming in this dry run.
