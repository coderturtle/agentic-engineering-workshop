# Persona: Instructional Designer — Module 01 — 2026-07-03

**1. The central pedagogical claim is asserted, then validated against the wrong control.** The README states plainly: "The discriminator against osmosis is reproducibility: one lucky pass is a plausible output; three-for-three is a specified one." But the only validation on record (`runs/2026-07-03-module-01-dry-run/README.md`) ran an already-tuned `candidate-prompt.md` three times and got 3/3. It never ran a *typical osmosis-level prompt* — the kind an advanced daily user would write without the module's discipline — to show it fails the bar. Without that negative control, "reproducibility separates specified from lucky" remains a claim, not a demonstrated result. This is exactly the gap the lens is supposed to catch: the exercise's core discriminating mechanism is untested against the thing it's supposed to discriminate from.

**2. Rubric gate-labeling contradicts the stated gate.** Criterion 1 is explicitly tagged "(gate)"; criterion 2, reproducibility — the very criterion carrying the anti-osmosis argument — is tagged "(scored)," implying partial credit. Yet "Required to advance" and "Stop condition" both describe reproducibility in absolute terms ("three times in a row," "no run touches the test file"). A grader following the rubric's own labels could pass a 2-of-3 learner on a "scored" item; the prose elsewhere says that's not a pass. The module doesn't resolve which wins.

**3. Edge-case criterion is gameable by design.** Rubric #3 scores whether "the prompt names the four edge cases" — but the exercise text itself lists all four verbatim ("empty input, a receipt whose UTC timestamp crosses a month boundary..."). A learner can score full marks here by copy-pasting the assignment's own enumeration, without ever practicing edge-case discovery. That's osmosis-proof in form, not substance.

**Credit where due:** the gate itself is real and unambiguous — "Reading this module does not count: you advance on a working, reproducible prompt, not on having read this page" leaves no read-and-move-on escape hatch.
