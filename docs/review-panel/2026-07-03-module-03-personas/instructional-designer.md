# Persona: Instructional Designer — Module 03 — 2026-07-03

**Top finding — the worktree learning objective doesn't survive the exercise.** The README lists "Isolate parallel work safely (worktrees) instead of colliding on a shared checkout" as a core learning objective, but the exercise text makes it explicitly optional ("Optionally isolate the work in a git worktree") and rubric criterion 5 states outright: "Not required: a plain isolated working copy satisfies the exercise if a worktree isn't used." Worse, the module's own reference run confirms the gap isn't hypothetical: `runs/2026-07-03-module-03-dry-run/README.md` states "Not exercised in this pass: rubric criterion 5 (worktree isolation)... a plain isolated directory was sufficient." The canonical "this is what a passing run looks like" example never demonstrates the third stated objective at all. A learner can complete Module 03 to spec, exactly as the reference implementation did, having never touched a worktree.

**The cumulative hook overclaims relative to the plan, and to the mechanism.** `docs/coachgremlin-implementation-plan.md`'s Module 03 section says the harness "runs the specified task repeatedly with the curated context" — i.e., Module 02's curated output feeds into Module 03's harness. The shipped README quietly downgrades this to "the harness runs the same kind of task, repeatedly, without you re-explaining scope every time." Mechanically, the exercise runs against `fixtures/receipts/`'s clean canonical state, not the budget-trimmed context from Module 02, and it re-stubs `group_expenses_by_category` from scratch rather than building on any artifact Module 01 or 02 actually produced. What's cumulative is fixture-family and CLI-shape continuity, not a mechanical pipeline — the same narrative-continuity-without-mechanical-link pattern already found in Module 02's claim to Module 01.

**Reset-and-resume gate has a copy-paste loophole.** Rubric criterion 3 only requires state that "resumes from it and completes correctly" — nothing forbids Phase 1 writing the complete solution into the notes file so Phase 2 merely transcribes it, satisfying the letter of the gate without demonstrating genuine incremental resumption. The stop condition anticipates dishonesty ("not a session that merely claims to have 'started fresh'") but supplies no concrete evidentiary requirement — no session ID, timestamp gap, or invocation command — beyond a transcript the learner authors and narrates themselves.

Minor: criteria 3 and 4 both fundamentally re-test "did this really happen, not staged," redundant gate weight on the same underlying risk.
