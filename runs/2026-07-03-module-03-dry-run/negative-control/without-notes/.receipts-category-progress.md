- `group_expenses_by_category` in `receipts/grouping.py` was already implemented
  when this session started (found complete, no changes needed). It groups
  parsed rows by the `category` field into a `GroupResult` (reusing
  `MonthSummary`/`RowError` dataclasses and the existing `_parse_row` helper),

  and the existing print loop (renamed loop var `month` -> `key` since it's now
  either a month or a category) handles output for both modes unchanged.
