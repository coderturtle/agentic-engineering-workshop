# Module 02 verification: curate under budget, rerun Module 01's task

## Method

Built `fixtures/receipts/variants/bloated/` (9,289 lines: a padded README, a 16-major-version CHANGELOG, a 220-class unrelated `legacy_export.py`, three stale docs, and a red-herring per-state tax-rate config), generated by `scripts/generate-bloated-variant.py`, not hand-written, so the noise is reproducible.

Curated it down by hand to exactly the load-bearing files for Module 01's task: `SPEC.md`, `receipts/grouping.py`, `receipts/__init__.py`, `tests/test_grouping.py`, `tests/__init__.py`. Deliberately cut `receipts/cli.py`: not imported by the test suite, so not load-bearing for this task even though it's part of the "real" package. Measured with `scripts/context-budget.sh`.

## Result

Curated set: 182 lines, ~2,300 estimated tokens. Well under the module's stated ~2,000-line budget, with margin. Ran Module 01's exact validated prompt against a fresh copy of the curated set, in an isolated subagent with no visibility into anything outside the curated directory. All 5 tests passed on the first try; independently reverified (test file untouched, suite rerun directly, not just trusting the subagent's self-report).

## What this validates

- Rubric criterion 1 (budget met): 182 / 2000 lines.
- Rubric criterion 2 (task still correct): 5/5 tests pass under the curated context.
- Rubric criterion 3 (necessary inclusion): the function under test and its signature were kept verbatim, not summarized; the task remained solvable.
- Rubric criterion 6 (no noise smuggled): the README, CHANGELOG, legacy module, stale docs, and tax-rate config were all excluded entirely, not trimmed.
